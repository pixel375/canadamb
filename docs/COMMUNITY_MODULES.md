# Community forums, events, and jobs

Community forums accept moderated discussions and replies. Brandon topics inherit Brandon, and the provincial portal can host topics for any supported Manitoba location or the whole province. Approval makes one discussion discoverable on the appropriate portals. Accounts can follow discussions, and approved replies produce in-app notifications for followers. Moderators can approve, reject, pin, lock, and remove individual replies.

Events have local calendars, location scoping, public detail pages, and internal moderation. Enter times in America/Winnipeg. Nonexistent and ambiguous times around clock changes are rejected, and accepted values are stored in UTC. An event that spans days appears on each overlapping local calendar day. Cancellation updates the public status while preserving a private note for the organizer and moderators.

Owners and managers post jobs from an active business profile. On BrandonMB, the posting must belong to a Brandon business branch. The board supports text, location, workplace, employment-type and pay filters, personal bookmarks, and an HTTPS application destination. Edits return to moderation, where the decision is bound to the reviewed posting version. A job stops appearing after its Manitoba closing date, and a bounded scheduled command updates its stored status.

A fresh database initializes these three modules. For an existing database, publish the desired module availability under CanadaMB Admin → Settings after migration. This preserves existing published settings, permissions, and site overrides. Test both portal views after publication.
