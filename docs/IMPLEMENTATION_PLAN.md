# CanadaMB Implementation Plan

Hostinger Business Web Hosting is the initial production constraint. Use a single private Laravel release and MariaDB database with a public-only bridge under public_html. GitHub prepares Vite assets. hPanel Git may update the private source stage, followed by a reviewed release command. Run background work from bounded cron invocations.

1. Exercise host routing, geographic publishing, permissions and theme inheritance with HTTP and browser tests. Build the shared public layout, network admin and identity.
2. Exercise administrative community drafts, preview, DNS/TLS readiness, geographic binding and activation.
3. Build business directory profiles, licensed CSV intake, verified account claims and moderated updates.
4. Build attributed news ingestion and publishing. Next add source polling, AI adapters, monitoring and job retry flows.
5. Build Marketplace listings, review, media, search, private messages and shared discovery. Extend category and moderation operations.
6. Build location-scoped forums and events. Add latest activity widgets and durable notifications.
7. Build jobs with business management, filters and expiration.
8. Build structured real estate with publication and monetization controls gated by Manitoba compliance review.
9. Build advertising and subscription entitlements. Verify payment and advertising workflows in test mode.
10. Validate deployment on the actual Business Web Hosting account with a private two-host staging run, tested backups, real SMTP, TLS, cron, SEO and launch review.

See [progress](PROGRESS.md) and the [Hostinger deployment runbook](DEPLOYMENT.md).
