# Deployment

CanadaMB uses one Laravel installation and database for the provincial portal and Brandon. Production and staging must fit Hostinger Business Web Hosting with precompiled assets and cron. See the [Hostinger production prelaunch runbook](HOSTINGER_DEPLOYMENT.md) for the private directory layout, exact SSH commands, migrations and recovery. Use the [deployment checklist](DEPLOYMENT_CHECKLIST.md) to record results before activating a release.
