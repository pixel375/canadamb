# Theme system

The super administrator edits light and dark CSS design tokens. Classic Blue, Clean Purple, Modern Teal and Neutral Slate provide palettes. A custom palette supports direct HEX input, a native picker and a live preview. Contrast checks flag selected text and background pairs. A draft can be published across both portals, and an earlier published configuration can be restored.

All portals render shared Blade components and one Vite asset build. The local header accent is stored on the site record. The editor accepts solid colors or gradients with configurable width, direction, radius and shadow. CanadaMB starts with a seven-color line and BrandonMB with green. Visitor appearance preferences persist per browser origin.
