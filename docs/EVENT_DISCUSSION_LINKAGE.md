# Event discussion linkage — review-staged

A one-to-one additive link table connects newly submitted events to companion discussion threads, created together in one transaction when CANADAMB_EVENT_DISCUSSIONS is enabled and Discussions is available. Both records start pending and are moderated independently. Links and event summaries are displayed only when both records satisfy existing publication, community and module rules. When an approved discussion is linked to an event awaiting review, show only a disabled Review pending control, never unpublished event fields or an event link. Calendar titles open the authoritative event details on the current domain, with a separate discussion link only when the linked discussion is publicly visible. Approved discussions display Go to event; cancelled events retain their notice. Cancelled events retain a cancellation notice in their public companion discussion. Rejected or hidden events do not expose private event details through discussion links. Existing events are not automatically backfilled. Editing the discussion does not alter official event dates or location. The proposed migration is not auto-discovered and the flag defaults false; explicit reviewed schema deployment and acceptance testing are required.
