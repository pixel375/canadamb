# Community configuration

Open Admin → Community websites. The add form saves an inactive draft. Choose a unique domain and an available Manitoba location, then configure the public identity, SEO details and header accent. Use Preview to review the same public home layout from the central administration origin. Preview responses are private and marked noindex.

At your host, configure ownership, domain routing and a trusted certificate. After verifying DNS and TLS, record both operator confirmations. Ready and Active require those confirmations. Activating an eligible site registers its exact OAuth callback through Passport. A site's host and location assignment are fixed at creation during this implementation. Coordinate any future domain change as a migration with redirects and replacement OAuth callbacks.

Global module settings inherit by default. A community can hide an available module when the network permits local overrides. Drafts and activation changes are audited. Connectivity checks currently use operator confirmations.
